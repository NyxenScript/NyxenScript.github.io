# Commands

| Command | Who | What it does |
|---|---|---|
| `/nyx_demo` | Anyone | Shows a sample form, then a notification. Good for testing. |
| `/nyx_config` | Needs `nyx_lib.config` | Opens the theme panel. Name can be changed in [`config.lua`](/nyx_lib/reference/config). In the server console it prints the current theme. |
| `nyx_theme <preset> [dark\|light]` | Server console, or needs `nyx_lib.config` | Changes the theme. |

See [Admin panel and commands](/nyx_lib/theming/admin-panel) for details.
